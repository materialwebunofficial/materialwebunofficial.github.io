# Security Policy

## Supported Versions

We provide security updates for the following versions of **MD3E Web (Unofficial)**:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The security of our users and open source community is a top priority.
If you discover a security vulnerability, please do **NOT** open a public GitHub issue.

Instead, please report the vulnerability confidentially:
1. Use GitHub's [Private Vulnerability Reporting](https://github.com/materialwebunofficial/materialwebunofficial.github.io/security/advisories/new) feature on the repository.
2. Or contact the core maintainers directly via email.

Please include:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction steps or a minimal proof of concept (PoC).
- Any relevant logs, screenshots, or proposed mitigation.

We will acknowledge receipt of your report within 48 hours and provide an estimated timeline for a patch.

What makes it expressive

Color with character

Start with one seed color. Material Color Utilities turn it into a complete scheme for surfaces, controls, light and dark themes, and contrast levels.

Shapes that respond

Buttons, chips, and toggles change shape as they are pressed or selected. The 35 shapes of the Material shape library are ready to use.

Motion with meaning

Springs drive movement and color. Spatial springs may overshoot a little, and effects springs settle without a bounce.

Get started

Add the design tokens and the components to any page. The library is plain JavaScript with no runtime dependencies, so it works with or without a framework.

Install

Package manager

For apps built with a bundler such as Vite or webpack.

npm install @materialwebunofficial/md3e-web
pnpm add @materialwebunofficial/md3e-web
bun add @materialwebunofficial/md3e-web

CDN

For a single HTML page, with no build step.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@materialwebunofficial/md3e-web/dist/tokens.min.css">

  return <md-button variant="filled" icon="check" label="Confirm"></md-button>;
}

Theming

A theme element generates the color scheme from a seed color. The expressive theme also selects the expressive motion scheme.

<md-expressive-theme global primary-seed="#00639B" color-mode="auto" palette-variant="tonal-spot">
  <!-- Your app -->
</md-expressive-theme>

Or apply a scheme from JavaScript:

import { applyDynamicTheme } from '@materialwebunofficial/md3e-web';

// Tonal spot, the default dynamic color variant, for the dark theme.
applyDynamicTheme('#00639B', true);

// Any other Material variant, such as vibrant or monochrome.
applyDynamicTheme('#00639B', true, 'vibrant');

Components

Components are interactive building blocks for creating a user interface. They are organized by purpose: actions, communication, containment, navigation, selection, and text input.

Actions

Buttons, FABs, and their variations help people take action and make choices.

Buttons

Buttons prompt most actions in a UI. They come in five sizes, and their shape responds to press and selection.

Default buttons Elevated, filled, tonal, outlined, and text buttons, from high to low emphasis.
<md-button variant="filled" label="Button" icon="add"></md-button>
Sizes Extra small (32dp) to extra large (136dp). Type and corner radius grow with the height.
<md-button size="m" variant="filled" label="Button"></md-button>

Button groups

Button groups organize buttons and add interactions between them. Standard groups react to presses; connected groups replace segmented buttons for selection.

Standard Press a button: it widens by 15% while its neighbors make room, then settles back with spring motion.

<md-button-group variant="connected" selection="single"><md-button icon="work" label="Work" selected></md-button>...</md-button-group>
